## Contexte

Je suis un geek : j’aime comprendre comment fonctionnent mes outils et les améliorer pour mon usage, pas seulement les utiliser. Ce qui m’intéresse, c’est ce qui change ma vie de tous les jours.

## Ce que j’ai fait

- Garder mes notes dans Obsidian, sur mon ordinateur, avec Claude intégré pour les retrouver et les reformuler
- Essayer l’IA en local, pour voir ce qu’elle permet sans envoyer mes données ailleurs
- Bloquer par DNS les réseaux sociaux les plus envahissants, couper les vidéos courtes et les notifications, pour garder mon attention
- Lire la presse plutôt que le fil des réseaux
- Utiliser Notion pour organiser les travaux d’équipe
- Sortir progressivement de l’écosystème Google et Microsoft : une démarche commencée, pas encore aboutie

## Ce que j’en retiens

Ce qui compte, c’est d’essayer soi-même. Une nouveauté n’est utile que si elle améliore vraiment un usage.
