Infrastructure T-Bird

Survolez ou touchez un élément : son rôle, ce dont il dépend, ce qui se passe s'il s'arrête.

  • Vital plus aucune vente
  • Important une fonction clé s'arrête
  • En retrait : secours, utile, à questionner

Bord en tirets : interchangeable. Bande à gauche : l'étage. Les liens secondaires s'allument au survol, ou avec « Tous les liens ».

Et si… ? Ce qui tient, comment repartir

Le PC casse

Tient : tout, le site n'en a pas besoin.

Perdu : le travail pas encore poussé sur GitHub.

Repartir : autre PC, code depuis GitHub ou Drive.

½ journée

Tout brûle à la maison

Tient : site, base, photos, copies.

Risque : se reconnecter sans le téléphone (double authentification).

Repartir : codes de secours gardés ailleurs.

Quelques jours

GitHub perdu

Tient : le site en ligne.

Perdu : mises à jour et sauvegarde quotidienne, le temps de repartir.

Repartir : code du PC ou du Drive vers un nouveau dépôt.

1 journée

Le serveur disparaît

Tient : base (Neon), code (GitHub, Drive), photos (Drive).

Perdu : les clés de Coolify, seulement sur le serveur.

Repartir : nouveau serveur, Coolify, clés, photos, DNS.

1 journée

La base est abîmée

Tient : code, photos, serveur.

Perdu : une journée de commandes au plus.

Repartir : sauvegarde de la nuit dans une base neuve.

Quelques heures

Une mise à jour casse le site

Tient : tout, rien n'est perdu.

Repartir : « Rollback » dans Coolify.

Quelques minutes
